# 魔多外语学习输入法

魔多基于青简开发，让日常打字与外语表达练习连接起来。客户端按 **GPL-3.0-or-later** 开源，先支持 Windows 与 Android。

- **基础免费**：中文拼音、中文整句组词、本地词汇译词、个人输入习惯学习；Android支持26键与9键。
- **学习会员20元/30天**：整句翻译、母语语音输入、外语语音释义与纠错、显示正确句子再跟读；每期1,000次整句翻译、120分钟语音。
- **跨设备学习**：账号同步主动收藏的卡片、学习语言与语音模式；云端同意在每台设备单独选择。

当前是开发版。没有支付商户号，暂不开放付款；会员通过受信任的本机管理员测试开通。基础功能不依赖会员服务。学习语言先支持英语、日语。

Android启用键盘后选择26键或9键。使用语音前，在魔多 App 中登录、同意云端处理并允许麦克风；完成当前选词后长按空格说话。Windows设置中有账号、会员和语音老师，录音后可回到输入框按F8插入主动准备的结果。

见[使用说明](docs/user/learning/modo-membership.md)、[构建与验收](docs/notes/modo-build.md)、[设计说明](docs/design/modo.md)。安装包使用开发签名，商用发行前仍须完成目标真机验收、数据授权核验和服务商商用范围确认。
