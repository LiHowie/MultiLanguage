# 魔多会员与语音老师

Windows双击魔多Setup.exe，确认管理员授权并点击「安装」。安装后自动启动输入服务，桌面和开始菜单的「魔多设置」可调整学习选项，Win+Space切换输入法。卸载在Windows「已安装的应用」中选择魔多。旧开发ZIP仍可用Install.cmd安装。

基础输入和本地单词译词免费，无需登录。整句翻译和语音老师会员为20元/30天；本期包含1,000次整句翻译和120分钟语音。当前是开发版，不开放付款，测试会员由运营人员开通。

Windows 在魔多设置的「会员与语音老师」页登录，同意云端学习，再在「云服务」页开启整句翻译。中文候选在停顿后显示完整译文，普通选词输出中文，Ctrl + 数字输出译文。会员失效和网络异常不会影响本地打字。

Android 打开魔多 App，启用并选择键盘。可在设置选择26键或9键、英语或日语学习语言、口语或书面风格。登录后选择是否允许云端学习和整句翻译。数字9键用于中文拼音，英语使用26键。

语音有两个模式：母语输入输出识别原文；外语学习给出中文含义、正确表达和解释。每次最多30秒。Android 先在 App 中允许麦克风，完成当前选词后长按空格录音，松开提交；外语学习结果出现后，可选择输出或按住跟读。设置 App 内也可练习和收藏。

Windows 点击开始录音，再点击停止。正确句子会留在页面上，可以看着再录一次。点击准备插入，回到普通输入框按F8输出；准备结果3分钟后失效，使用一次后清除。可在配置文件的 `[shortcut] voice_insert` 修改虚拟键码或设为0关闭。

Windows可点击「取消录音」丢弃本次结果；切换设置页、切换语音模式或撤回云端同意也会取消。退出账号会清除本机令牌和准备插入的语音文字。

主动收藏的学习卡片、学习语言、安卓键盘布局与语音模式可同步。先拉取最新记录，再同步本机设置。云端处理的同意在每台设备单独选择，不随账号打开。

AI 结果可能有误，语音老师提供表达建议，不做发音评分。麦克风或网络请求失败时会显示原因，模型失败不会扣本次服务额度。
