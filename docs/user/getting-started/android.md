## 安装与启用

魔多 Android 开发版支持 Android 8.0 及以上。

1. 安装魔多 APK，打开「魔多输入法」。
2. 点击「启用魔多键盘」，在系统设置中开启魔多。
3. 返回魔多，点击「选择输入法」，选择魔多。
4. 在「中文键盘」选择26键或9键，点击「保存学习设置」，重新打开键盘。

基础拼音、组词、本地译词和输入习惯学习免费，不用登录。九键按手机数字对应的字母输入拼音，例如「你好」按64426，再选择「你好」。候选行可以左右滑动。

## 会员整句翻译

账号与会员页填写魔多服务地址（含 `/v1`），登录或注册。开发版暂无付款，测试会员由本机运营人员开通，权益为20元/30天的整句翻译与语音老师。
在学习设置中选择英语或日语、口语化或书面化，同意云端处理，开启会员整句翻译并保存。

完整输入拼音后停顿，当前候选译文显示在键盘上方。点击中文候选输出中文，点击「输出译文」输出外语。继续输入或删除时译文更新，联网失败不影响基础输入。

云端只收到本次待翻译文字，不读取宿主输入框的其他内容。云端同意在每台设备单独选择。

## 语音老师

登录有效测试会员后，同意云端处理并点击「允许麦克风」。选择母语输入或外语学习模式，保存设置。

- 完成当前选词后，长按空格开始录音，松开提交，单次最长30秒。
- 母语输入会输出识别原文；外语学习显示母语含义、正确表达和解释，确认后点击「输出」。
- 点击并按住「跟读」可以看着正确句子再说一次，AI提供文字辅助，不进行发音评分。
- 设置页也可按住录音、复制结果、收藏纠正句子和拉取学习卡片。

录音取消或切换输入框会作废旧结果，原始录音不保存到文件。

## 常用操作与隐私

「中英」切换中文和英文，「123」打开数字符号，「ABC」返回字母；九键的「26键」可直接切换布局。「⌫」先删拼音，再删输入框文字。「↵」在组词时选词，否则执行输入框完成操作或换行。「🌐」切换系统输入法，「设置」打开魔多设置。

密码框直接输入，不学习、不发送翻译或语音请求。应用要求禁止个性化学习时也停用云端功能。账号令牌由系统密钥库加密保存在应用私有目录，不参与系统备份；学习卡片只同步主动收藏的内容。

本版使用开发签名，尚未完成各手机厂商的真机兼容性验收。服务尚未公网部署；本机 Android 模拟器默认连接 `http://10.0.2.2:8797/v1`，手机需填可访问的HTTPS服务地址。
