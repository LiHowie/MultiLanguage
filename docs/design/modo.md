# 魔多产品与服务边界

魔多基于青简，是 GPL-3.0-or-later 的外语学习输入法。独角是另外一款独立闭源产品；两者只按明确的数据和接口契约协作，不把 GPL 实现反向复制进独角。

基础输入、本地单词译词、词频学习和中文整句组词无需账号或会员。整句 AI 翻译和语音老师使用魔多账号服务；服务端核验会员，价格为 20 元/30 天，每周期 1,000 次整句翻译和 7,200 秒语音。语音纠错按语音秒数计量，不重复扣翻译次数。网络或会员服务不可用时，基础输入继续运行。

第一阶段平台是 Windows 和 Android。Android 中文支持 26 键与 9 键，英语使用 26 键。学习语言为英语或日语，一次只显示一种辅助语言。9 键解码、排序、组句和数字消耗位于 Core 的 `engine/keypad/`；平台只提交数字和候选选择。候选由数字索引和有界搜索产生，复用词频和 bigram，选择前缀词后余下数字继续输入。当前索引在首次使用九键时创建，新增用户词重新加载后进入索引。

会员整句翻译的防抖和过期结果隔离沿用 Core。`qingjian-predict::MembershipClient` 访问 `/v1` 服务，只发送本次主动产生的候选文字或录音，不读宿主全文。供应商密钥仅存服务端；客户端只有魔多会话令牌。Android 用 Keystore 加密保存令牌；Windows 令牌在本用户配置内，日志导出沿用凭证隐藏规则。

语音老师使用 WAV 16kHz、单声道、16位 PCM，单次最长30秒。母语模式保留识别原文；外语学习模式返回母语含义、纠正句子、解释和日语读音。跟读保留正确句子并重新录音，不宣称发音测评。Android 长按空格录音，在设置中先允许麦克风。Windows 原生学习页录音，用户点击准备插入后回到输入框按 F8；准备结果3分钟后失效，读取时删除且仅消费一次，私密输入框不插入。

云端同意由各设备单独选择，不随账号同步。密码和禁止个性化学习的输入框关闭云功能。录音取消、输入框变化与页面失焦会作废结果；不保存原始录音。账号只同步主动收藏卡片和学习语言、键盘布局、语音模式，使用版本号处理冲突。

尚无支付商户号。本版不提供付款或公开会员开通接口。仅受信任的本机运营人员在 `MODO_TEST_MODE=1` 时通过 `scripts/plan.mjs` 开通测试会员。正式支付需另接商户渠道、验签、幂等回调、退款和恢复购买；不能把测试开通宣传成已接支付。

正式部署前完成供应商商用范围确认、数据许可核验、HTTPS、备份、邮箱验证与找回密码等运营能力。安装包属于开发版，Windows 为未公开签名包，Android 使用开发签名。
