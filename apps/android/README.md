# 魔多 Android 测试版

Android 8.0 及以上。中文26键/9键、整句组词、本地译词、英文与符号键盘；会员整句翻译、语音老师和学习卡片同步。学习语言先支持英语与日语。

安装 APK 后打开「魔多输入法」，启用并选择键盘，在中文键盘设置中选择26键或9键。基础输入无需账号。使用云端学习时，填写魔多服务地址，登录测试会员、同意云端处理，再开启整句翻译或允许麦克风。
输入拼音并停顿后，译文出现在候选区。点击中文候选上屏中文，点击「输出译文」上屏外语。候选行可左右滑动查看其他候选。

工程构建与验证见 [Android 工程记录](../../docs/notes/android.md)，使用说明见 [Android 用户文档](../../docs/user/getting-started/android.md)。

这是独立开发版，尚未发布到应用商店。整句翻译和语音老师需联网，由服务端核验20元/30天会员；目前只有本机运营人员测试开通，没有付款入口。手机连接服务需HTTPS地址，模拟器默认使用本机服务。模型密钥只配置在服务端。
